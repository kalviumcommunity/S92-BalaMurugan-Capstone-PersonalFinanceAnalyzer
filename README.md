# SpendLens - Personal Finance Analyzer

## Project Overview

SpendLens is a MERN-stack web application that helps users track their income and expenses, categorize spending, and visualize their financial habits through charts and reports. The goal is to give users a simple, clear way to understand where their money goes and make better financial decisions.

## Day-by-Day Plan

- **Day 1-2:** Project setup — repo structure, README, initial planning, tech stack finalization.
- **Day 3-4:** Design Mock UX (Figma) — define screens, navigation flow, and user journeys.
- **Day 5-7:** Backend setup — Node.js + Express server, MongoDB schema design (Users, Transactions).
- **Day 8-10:** Authentication — signup/login with JWT, protected routes.
- **Day 11-13:** Core feature — Add/Edit/Delete transactions (API + frontend form).
- **Day 14-16:** Dashboard UI — display balance, recent transactions, summary cards.
- **Day 17-19:** Reports & Analytics — charts for category breakdown and monthly trends.
- **Day 20-21:** Profile/Settings page, polish UI, responsive design.
- **Day 22-23:** Testing, bug fixes, and performance optimization.
- **Day 24-25:** Deployment (frontend + backend), final documentation, and demo prep.
